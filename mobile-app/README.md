# Lottery Helper Mobile App

A React Native mobile application for lottery statistics, number generation, and ticket tracking.

## Features

- **Random Number Generator**: Generate lottery numbers with customizable ranges
- **Statistics Analysis**: View frequency analysis and probability calculations
- **Ticket History**: Track your lottery tickets and spending
- **Educational Content**: Learn about lottery mathematics and probability

## Important Disclaimer

This app is for entertainment and educational purposes only. Lottery numbers are completely random and cannot be predicted. Past results do not influence future draws.

## Setup

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Run on device/simulator:
   ```bash
   npm run android  # For Android
   npm run ios      # For iOS
   ```

## App Structure

- `App.js` - Main navigation and theme setup
- `src/screens/` - All screen components
  - `HomeScreen.js` - Welcome screen with quick actions
  - `GeneratorScreen.js` - Random number generation
  - `StatsScreen.js` - Lottery statistics and probability education
  - `HistoryScreen.js` - Personal ticket tracking

## Technology Stack

- React Native with Expo
- React Navigation for navigation
- React Native Paper for UI components
- Vector Icons for iconography

## Educational Purpose

This app emphasizes that:
- Lottery numbers are completely random
- No system can predict lottery outcomes
- Each draw is independent of previous results
- The mathematical odds remain constant regardless of number selection
